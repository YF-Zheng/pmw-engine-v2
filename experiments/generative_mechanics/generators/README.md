# Offline Generator Boundary

The lab defines a versioned JSONL request/response protocol, not a model SDK. It contains no HTTP client, credentials, retry loop, or hidden network call. A provider adapter renders the canonical request and returns an untrusted envelope carrying provider/model identity, prompt hash, seed, and raw response ID.

`world_substrate` responses contain strict SkillSpec v0.1 mechanics over the
eight public channels. `isolated_direct_effect` is the narrow direct-only
control. `matched_direct_outcome` has the same structural expression budget as
the substrate condition while still writing only `direct_outcome.*`. Generic
world laws never read that component.

The checked-in 240-sample data is generated by a deterministic fixture provider solely to exercise the pipeline. It is always marked `source_kind=deterministic_fixture` and must never be reported as model output or a paper result.

## Protocol v0.2-Controlled

`gm-generation-v0.1` remains frozen for replaying the original fixture run.
The controlled-invention track is formally frozen as **Protocol
v0.2-Controlled**. New collection uses the revisioned machine identifier
`gm-generation-v0.2-controlled` and the explicit
`*_v02` APIs in `generation.py`. The baseline identifiers are:

- `isolated_direct_effect`: the original compact direct-only control.
- `world_substrate`: SkillSpec mechanics that perturb public world channels.
- `matched_direct_outcome`: a direct-only control with multiple effects,
  public trigger conditions, duration or periodic behavior, costs, charges and
  slot cost. It writes only `direct_outcome`; generic world laws do not read it.

Every v0.2 sample has a coordinate-derived seed, nonce and ID. All three are
inside the canonical prompt, making prompt hashes unique even within one
baseline/band cell. Controlled envelopes also carry `master_seed` and
`sample_index`; ingestion re-derives and verifies the ID, seed, and nonce before
checking the prompt hash. The prompt discloses only the eight channel semantics, a
machine-readable channel-level summary derived from frozen generic world laws,
and two versioned, baseline-specific calibration examples per target band. A
prompt contains exactly six examples matching its own response schema; the
other two baselines' examples are never disclosed. All 18 scores are frozen in
`calibration_examples_v0.2-controlled.json` and are reproducible through the
corresponding compiler and the authoritative scorer over the six calibration
scenarios. It contains no world
instance, evaluator state, or private material/process values.

The archived `gm-generation-v0.2` revision remains ingestible. Validation
reconstructs its original shared-six-example canonical prompt; it never checks
an archived response against the Controlled prompt. Prompt hashes from the two
revisions are intentionally non-interchangeable.

Provider requests and response envelopes remain UTF-8 JSONL. Each bad response
is reported independently by `ingest_jsonl`; it cannot discard valid sibling
rows. `archive.build_deterministic_archive` fixes entry order, timestamps, Unix
modes and compression settings for byte-identical archival output.

Structural diversity uses topology and coarse numeric bins, ignoring IDs and
names. Parametric diversity hashes exact numeric parameters. Report these
separately: a small parameter perturbation may change the latter without
creating a new structure.

```text
provider response JSONL
  -> strict envelope/provenance validation
  -> strict mechanic validation
  -> trusted compiler
  -> calibration or evaluation PMW execution
  -> contextual build search / analysis
```

The preregistered small pilot is 15 samples per baseline/band cell: 3 baselines
times 3 bands times 15, for 135 genuine model responses. The repository does
not contain a provider credential or silently substitute deterministic fixture
rows when a provider is unavailable.

## Protocol v0.3-Free-Invention

The independent free-invention track uses `gm-free-invention-v0.3` and the
`generate-free-invention-requests` command. Its machine contract is
`protocol_v0.3.json`; it deliberately has no score bands, scored examples, or
revision stage. See `../FREE_INVENTION_V03.md`.
