## Counting Contract

主要来源是Codex rollout `token_usage_record.payload.usage`：input含缓存，
cached是其中命中量；output已含reasoning。按thread+response ID去重。
不把`thread_token_usage`、`turn_token_usage`重复相加；历史会话不全部记入本项目。
Unknown或缺失记录独立保留，预算门禁必须fail closed，不能当作零费用。
不复制原始prompt、Token鉴权、API Key、配置或聊天全文。

```text
USD = input * (0.03 * uncached_price + 0.97 * cached_price) / 1,000,000
    + output * output_price / 1,000,000
```

97%仅用于参考费用，不改写实际cached_input_tokens。
输入和输出价均按单个请求的官网规则处理。全部原始安全计数供复核。
