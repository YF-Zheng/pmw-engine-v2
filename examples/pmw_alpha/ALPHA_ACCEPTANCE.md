# Alpha Acceptance

Alpha is not accepted until all conditions below are demonstrated.

- Five Areas appear in a browser map, with hidden information withheld until
  inspection or relevant discovery.
- A player can gather, craft, register, equip, and use each core/modifier
  family through normal UI commands; all 12 combinations compile.
- Active skills are selectable in combat.  Player and enemy states, weather,
  shields, and observable intents are visible.
- Forest intervention survives travel and multiple World Ticks before opening
  the root bridge.  Mine power opens a durable lift and changes the Observer.
- Normal combat and stable-seal routes both reach a real ending; death and
  time exhaustion reach Seventh Night.
- Save/load round-trips WorldState, registry, dynamic effects, time, map
  links, knowledge, and ending state without duplicate processing.
- Tests cover atomic rejection, resource competition, incorrect weather,
  passive expiry, route unlocks, boss power effects, all endings, and UI/API
  consistency.  Frozen Core and M0 suites continue to pass.
- Browser verification records camp, exploration, crafting, combat, world
  change, and ending screens.  If browser automation is unavailable, that
  limitation is stated explicitly.
